# Easilys / MAPAL mock API module

This module is part of the combined seven-API application. Deploy the **project root**, not this folder by itself. Its base path is `/easilys`.

- Health: `GET /easilys/health`
- Locations: `GET /easilys/locations`
- Resource endpoints: see the root [`API-ENDPOINTS.md`](../../API-ENDPOINTS.md).

The root project provides the single Render deployment and runs the shared test suite.
