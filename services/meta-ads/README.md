# Meta Ads mock API module

This module is part of the combined seven-API application. Deploy the **project root**, not this folder by itself. Its base path is `/meta-ads`.

- Health: `GET /meta-ads/health`
- Locations: `GET /meta-ads/locations`
- Resource endpoints: see the root [`API-ENDPOINTS.md`](../../API-ENDPOINTS.md).

The root project provides the single Render deployment and runs the shared test suite.
